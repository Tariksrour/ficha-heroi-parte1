# Vulcano — Ficha de Herói

Projeto acadêmico desenvolvido com HTML e CSS para apresentar
um personagem original em uma página inspirada em uma ficha de RPG.

## Sobre o personagem

Vulcano é um Guerreiro-Arquiteto Digital nascido nas fundições
de Ostrogard. Ele transforma sucata em invenções, constrói
defesas e protege seu reino.

Sua habilidade especial, Regeneração de Construção, exige
o Martelo de Ostrogard equipado.

## Tecnologias utilizadas

- HTML: estrutura e conteúdo.
- CSS: cores, layout, barras de atributos e responsividade.
- Google Fonts: fonte Rajdhani.

## Como abrir

1. Baixe e extraia a pasta do projeto.
2. Mantenha o index.html, o style.css e a pasta imagens juntos.
3. Abra o arquivo index.html em um navegador.

É necessário acesso à internet para carregar a fonte Rajdhani.
Também é possível abrir o projeto no VS Code usando Live Server.

## Seções da página

- Sobre o Herói.
- Atributos e Habilidades.
- Regeneração de Construção.
- Inventário e Conquistas.
- Contato com a Guilda.

## Decisões de UI/UX

### Hierarquia visual

O nome do personagem tem tamanho maior, e os títulos usam
laranja para destacar o início de cada seção.

### Contraste e legibilidade

Os textos claros aparecem sobre caixas escuras para facilitar
a leitura sobre a imagem de fundo.

### Consistência

Os cartões e as barras repetem cores, bordas arredondadas
e espaçamentos, mantendo uma identidade visual comum.

### Proximidade e agrupamento

Cada atributo reúne nome, porcentagem e barra na mesma caixa.
Cada item do inventário reúne nome, raridade e descrição.

### Indicação de interação

Os links possuem estilos de hover e foco para indicar
quando estão sob o ponteiro ou selecionados pelo teclado.
